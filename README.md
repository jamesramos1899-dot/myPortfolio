# James Ramos — Portfolio

Personal portfolio of **James Stephen Ramos**, a 4th-year BSIT student at the University of Cebu Lapu-Lapu and Mandaue (UCLM), working toward becoming a full-stack developer.

## Highlights

- **Eyes that follow your cursor**: a dithered photo drawn on a canvas, with real-time eye tracking and blinking
- **Guided tour**: a pixel cursor that walks visitors through every section
- **Ask anything**: a chat assistant that first shows what your browser reveals (IP-based location, device, specs, timezone). Nothing is stored.
- **Project console**: live mini-demos of each project
- **Experience as `git log --graph`**, a terminal-style "system check", and a darkroom certificate gallery
- Typing test, community chat, floating dock navigation, light / dark mode

## Tech

Plain HTML, CSS and JavaScript. No framework and no build step.

## Run locally

Open `index.html` in a browser.
